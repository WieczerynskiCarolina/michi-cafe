# MichiCafé & Refugio

MichiCafé es una página web ficticia para una cafetería de especialidad que funciona al mismo tiempo como refugio para gatos. Este proyecto fue desarrollado como pre-entrega para el curso de Front-End.

## Características
- Catálogo de productos de la cafetería
- Galería de adopciones
- Diseño responsivo
- Navegación fija e interactiva
- Contenido multimedia
- Formulario de contacto

## Tecnologías utilizadas
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Formspree
